# dreamdex-perps-feedback

Reproducible feedback on the dreamDEX perps API, SDK and docs (Somnia Hideki testnet, `@somnia-chain/markets-sdk` 0.32.1).
Each report in `feedback/` has a matching script in `repro/` and captured output in `evidence/`.

Run a repro: `npm install && node repro/NNN-<slug>.mjs`.
